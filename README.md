# Football Insight Hub ⚽📊

A modern football analytics dashboard that provides insights, statistics, and visual data related to football performance. Built with **React**, **Vite**, and **Tailwind CSS**, this project focuses on clean UI, fast performance, and responsive design.

🔗 **Live Demo:**  
https://football-insight-hub.vercel.app/

---

## ✨ Features

- Interactive football statistics dashboard
- Clean and responsive user interface
- Fast performance with Vite
- Modern design using Tailwind CSS
- Mobile-friendly layout

---

## 🛠️ Tech Stack

- **React** – Frontend UI library
- **Vite** – Build tool and dev server
- **JavaScript (ES6+)**
- **Tailwind CSS** – Utility-first styling
- **Vercel** – Deployment platform

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Ayosensei/football-insight-hub.git
```

### 2. Navigate into the project

```bash
cd football-insight-hub
```

### 3. Install dependencies

```bash
npm install
```
### 4. Start the development server

```bash
npm run dev
```
